# GWC Design-A-Thon Project 2026: Grant Application Problem

Run the Python algorithms by providing 3 arguments:
* dataset file (e.g., dataset.csv)
* budget (e.g., 50000)
* sorting/scoring heuristic (3 options: "impact_to_score_ratio", "impact", "people)

Example:
`python3 grant_greedy_knapsack.py dataset.csv 50000 impact_to_score_ratio`

Results will be printed to terminal.
